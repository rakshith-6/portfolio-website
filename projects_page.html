A pick and place 4-DOF robotic arm

4-DOF Robotic Arm (Version 1.0)

Overview :

  • 4-DOF Robotic arm having Jaw Gripper as an end effector.
  • Two rotary actuation mechanisms — one at the Jaw Gripper and the other at the Base — a vertical linear actuation mechanism, and a horizontal linear actuation mechanism.
  • SG and MG servo motors (both full and 180° rotation) of required torque ratings were used for different actuation mechanisms.
  • Arduino Uno microcontroller was used to control the robotic arm. A lithium ion battery pack powered the entire setup.

1. Countdown Timer

Overview : This project uses an Arduino Nano to create a countdown timer that triggers buzzers at multiple instants (2 warning and one final buzzer) when the time reaches zero. This was deployed in a foundry workshop to manage the production time.

Full Assembly

Schematic Diagram

Exploded View Animation

Features :

  • A 16x2 LCD display shows the countdown in HH:MM:SS format. A pushbutton starts/stops the timer, and a rotary encoder with push button sets the time.
  • The buzzer is controlled via a 5V relay, powered by a 220V AC supply.
  • The Arduino Nano is mounted on an I/O shield, simplifying connections and allowing easy replacement if necessary.

How to operate the countdown timer:

  • Start/Stop pushbutton: Pressing the button will start the countdown, long pressing it again will stop the timer.
  • Rotary encoder with pushbutton:
    • The pushbutton of the rotary encoder can be operated as both SET and RESET buttons. Pressing the button will take the timer to SET mode; pressing it again navigates through seconds, minutes and hours in the display to set them accordingly.
    • Long pressing after SET operation will RESET the timer. The previously set time period remains the same unless reset. Rotating the knob counter-clockwise decrements time in HH:MM:SS, and rotating it clockwise increments time in HH:MM:SS.

Design, development, and documentation of a 6 legged spider bot.

Overview

A 6 legged articulated robot which can navigate in non flat, rough terrains. The bot has 6 controlled legs, each with 3 degrees of freedom, providing a total of 18 DOF.

Full Assembly

Leg Assembly

Mechanical design and fabrication

  • The robot's mechanical components were 3D printed using a Bambu X1 Series printer, using Bambu PLA black and white material.
  • Each leg has three actuated joints (between 4 links namely main body, coxa, femur and tibia):
    • Body-Coxa: attaches to the main body, handles horizontal sweeping.
    • Coxa-Femur: helps in lifting and lowering the leg.
    • Femur-Tibia: helps the leg to make and break contact with the ground.
  • With these joints each leg is independently actuated, allowing the robot to adjust the position of individual feet according to the terrain.

Actuation

  • All 18 joints are actuated using MG90S micro servos which provide stall torque of 1.8kg-cm at 4.8V and 2.2kg-cm at 6V.
  • With 3 servos per leg and 6 legs in total, 18 servos are used.

Power systems

A single 3s 1000mAh LIPO battery with fully charged ~12.6V and nominal voltage ~11.1V is used as power supply by the robot.

Servo power

  • Micro servos can't be powered directly with this battery as they need an operating voltage of 4.8 to 6V only.
  • During high load or stall conditions, the micro servo can draw 800mA and up to 1A, so a proper power conversion system is needed.
  • To draw sufficient current, the LiPo battery is connected to a 5V 15A DC to DC buck converter, which steps down the battery voltage to a 5V supply.

Arduino power

  • The regulated 5V output from the DC-DC buck converter is connected directly to the Arduino's 5V and GND pins. The Arduino draws up to 50mA.
  • Another option would be to connect the LiPo battery directly to the Arduino VIN/barrel jack input, which takes 7-12V input, but the onboard voltage regulator is linear so the excess voltage potential is dissipated as heat, which is unsafe.

PWM servo control

  • The 18 servos (9 on each board) are controlled using two PCA9685 16-channel PWM driver boards.
  • A PCA9685 driver board can control up to 16 servo motors using two pins (SDA and SCL) on the Arduino via I²C communication protocol.
  • To make the Arduino tell the difference between boards, the address of the second board was changed by soldering one of the I2C A0 address jumpers/patch.
  • The two boards are daisy chained (the first board's second set of SDA, SCL and VIN is connected to the second board) using jumpers.

Overall architecture

  • The LiPo battery connects to the 15A DC-DC buck converter, which supplies a high current 5V supply (set using the knob) for servos and Arduino.
  • The Arduino communicates with both PCA9685 boards via the I²C protocol.
  • A common ground is maintained between the Arduino, PCA9685 boards, and servo power system.
